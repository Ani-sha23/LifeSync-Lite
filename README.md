#  LifeSync Lite – Smart Personal Management System

##  Overview

LifeSync Lite is a Java-based console application designed to help students and professionals manage their daily life efficiently. It integrates expense tracking, task management, and habit tracking into a single unified system.

This project was developed as part of the **Programming in Java ** course.

---

##  Problem Statement

Managing expenses, deadlines, and habits across multiple platforms is inefficient and leads to poor productivity and financial mismanagement.

---

##  Solution

LifeSync Lite provides a **single platform** to:

* Track daily expenses
* Manage tasks with priorities
* Monitor habits and streaks
* Generate basic insights for better decision-making

---

##  Features

###  Expense Tracker

* Add and view expenses
* Categorize spending (Food, Travel, etc.)
* View total spending

###  Task Manager

* Add tasks with priority (High/Medium/Low)
* Automatically sorted tasks

###  Habit Tracker

* Track daily habits
* Maintain streak count

###  Insights Engine

* Displays spending trends
* Highlights high-priority tasks
* Shows best-performing habits
